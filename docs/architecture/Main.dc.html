Layers and dependencies
Each layer imports only the layers below it, with the exceptions drawn as dashed arrows. Folders are under lib/ unless named otherwise.
ui/  screens, sheets, shared widgets
Home, Plan, Pay, Export and Team tabs, Settings, onboarding. ConsumerWidgets watch providers and write only through services.
app/  wiring
AppServices: one per isolate, owns the repositories and services. Riverpod providers wrap drift streams. Theme, shift colours, update controller.
platform/  Android integration
NotificationService (reminders, running notification), CalendarSync, device setup, launcher icon, in-app update.
domain/  rules
PlanningService, RecordingService. Rounding, month summary, export text, reminder planner, tips, salary, team roster. 92% of lines tested.
data/  drift database and repositories
9 tables. Repositories for shifts, settings, tips, wages and the team roster. The drift row classes are also the domain models.
core/  helpers
Day keys, ISO weeks, minutes of the day, HH:mm, hours and euro formatting.
Kotlin
calendar_bridge and running_progress plugins. MainActivity: icon, updater.
l10n/  texts
German template, English. Used by every layer above core.
SQLite file
One drift server that both isolates share.
